\section{Conclusion}\label{sec:conclusion}
\vspace{-0.2em}
We presented SOMA, an efficient multi-turn LLM serving framework that uses early dialogue turns to adapt a small surrogate to the original model's session-local behavior. \rev{It probes the surrogate with adversarial soft prompts, distills the robustly anchored warm-start turns with LoRA, and switches only when alignment is sufficient.} Experiments show that SOMA better preserves original-model responses, improves task-grounded quality, and reduces serving cost once warm-start overhead is amortized. These results suggest that session-local surrogate serving is a practical direction for efficient multi-turn LLM deployment \rev{when sessions are long and locally coherent enough to amortize the warm-start cost, as Figure~\ref{fig:operating}(a) quantifies}. \rev{Because SOMA only consumes the original model's text outputs, it also applies when $F$ is a proprietary model behind an API, provided that the surrogate's embedding layer is accessible for mining.} \rev{In practice, SOMA is most useful for sessions that run beyond a handful of turns on a single task, and it degrades gracefully otherwise, because the gate keeps short or drifting sessions on the original model. We discuss the limitations of SOMA and directions for future work in Appendix~\ref{sec:limitations}.}
