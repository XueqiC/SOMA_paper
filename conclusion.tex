\section{Conclusion}\label{sec:conclusion}
\vspace{-0.2em}
We presented SOMA, an efficient multi-turn LLM serving framework that uses early dialogue turns to adapt a small surrogate to the original model's session-local behavior. \rev{It probes the surrogate with adversarial soft prompts, distills the robustly anchored warm-start turns with LoRA, and switches once the alignment looks sufficient.} Experiments show that SOMA better preserves original-model responses, improves task-grounded quality, and reduces serving cost once warm-start overhead is amortized. These results suggest that session-local surrogate serving is a practical direction for efficient multi-turn LLM deployment \rev{when sessions are long and coherent enough to amortize the warm-start cost, as Figure~\ref{fig:operating}(a) indicates}. \rev{Since SOMA only uses the text outputs of the original model, it should also apply when $F$ is a proprietary model behind an API, as long as the surrogate's embedding layer is available for mining.} \rev{In practice, SOMA seems most useful for sessions that stay on one task for more than a handful of turns. For short or drifting sessions the gate mostly keeps the original model in charge, which should limit the loss in quality. Two questions remain open, namely how SOMA behaves under gradual topic drift and how it compares with divergence-weighted fine-tuning at the same LoRA budget. On the theory side, our acceptance bound needs held-out turns and is loose at the batch sizes we use, so a variance-aware test on held-out turns could make the switching rule more reliable. We discuss these and other limitations in Appendix~\ref{sec:limitations}.}
